# AdminBolt

Documentation & Setup guide for the AdminBolt provider.

The provider uses the AdminBolt REST API, documented in the [Billing Integration API guide](https://docs.adminbolt.com/user-guide/integrations/billing-integration-api.html). It needs AdminBolt 1.8.2 or newer, the first version that filters accounts by exact username and accepts a plan by its name.

## Functions

AdminBolt identifies hosting accounts by their username, so every function only needs the username.

| Function | Supported | Notes |
|---|---|---|
| create() | Yes | Creates an account with the order's domain on the plan named by the package. A username and password are generated by the panel if not provided. Reseller accounts (`as_reseller`) are not supported |
| getInfo() | Yes | Returns the domain, the plan name and the suspension state |
| getUsage() | Yes | Disk space and bandwidth in MB, and mailboxes. A limit of 0 on the panel is unlimited and is returned as no limit |
| getLoginUrl() | Yes | Returns a single-use sign-on URL to the account's control panel, valid for 30 minutes. Login tokens are not available, so a URL is returned when `type` is `token` |
| changePassword() | Yes | |
| changePackage() | Yes | The plan must exist (see [Packages](#packages)) |
| changePrimaryDomain() | No | |
| suspend() | Yes | Succeeds if the account is already suspended |
| unSuspend() | Yes | Succeeds if the account is not suspended |
| terminate() | Yes | Deletes the account. Succeeds if the account no longer exists |
| grantReseller() | No | |
| revokeReseller() | No | |

## Configuration

| Field | Description |
|---|---|
| Hostname | Hostname of the AdminBolt server, e.g. `server1.example.com`. It must match the panel's TLS certificate unless Ignore SSL Errors is set |
| Port | Port of the panel. AdminBolt uses `8443` by default |
| API Key | API key of an administrator or a reseller (see [Creating an API key](#creating-an-api-key)) |
| API Secret | API secret of the same key pair |
| Use Reseller API | Set when the key pair belongs to a reseller. Accounts are then created under that reseller, and only that reseller's plans and accounts are available |
| Ignore SSL Errors | Do not verify the panel's TLS certificate |

## Creating an API key

- An administrator creates a key pair in the admin panel under **Security** > **API Keys**.
- A reseller creates a key pair in the reseller panel under **Security** > **Api Keys**.

The secret is shown only once, when the key pair is created. Use a dedicated key pair for Upmind and enable its IP whitelist with the addresses Upmind connects from. The panel allows 120 API requests per minute per key and calling address.

## Packages

The package name is matched to an AdminBolt hosting plan by the plan's exact name. Create the plans in AdminBolt before provisioning accounts. With Use Reseller API set, the plans must belong to that reseller.
